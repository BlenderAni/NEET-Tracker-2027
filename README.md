# 📚 NEET Tracker 2027

A clean, browser-based study tracker built for NEET aspirants.

NEET Tracker helps you record study sessions, monitor daily consistency, track weekly and monthly goals, and maintain a complete study history, all using local browser storage.


## ✨ Features

### 📝 Study Journal
### ⏱ Study Timer
### 📅 Interactive Study Calendar
### 📚 Session History
### 🎯 Weekly and Monthly Target



## 🛠 Built With

- HTML5
- CSS3
- JavaScript
- LocalStorage API

No frameworks.
No libraries.
Everything runs entirely in the browser.



## 💾 Data Storage

All study data is stored locally in your browser using **LocalStorage**.

No account or internet connection is required after loading the page.



## 🎯 Purpose

This project was built to create a distraction-free study tracker focused specifically on long-term NEET preparation.

Instead of relying on large productivity apps, the goal was to build a lightweight tracker that is fast, simple, and completely owned by the user.
